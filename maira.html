ETF MAiRA Conveyor / Local demo

Run the conveyor simulation

The GitHub repository contains the simulation code and robot description. You need Ubuntu 22.04 with ROS 2 Humble and its packages. RViz renders the mock arm. The demo runs without a physical MAiRA, a PLC, vendor drivers, or Gazebo.

1. Set up Ubuntu and ROS 2 Humble

Use an Ubuntu 22.04 desktop or Ubuntu 22.04 in WSL 2 with GUI support on Windows. Follow the ROS installation guide to set up the package repository and install ROS Desktop. Then run these commands inside Ubuntu.

ROS 2 Humble installationWindows GUI support
sudo apt update
sudo apt install git ros-dev-tools ros-humble-moveit \
  ros-humble-ros2-control ros-humble-ros2-controllers
# Skip init if rosdep is already initialized.
sudo rosdep init
rosdep update

2. Build only the simulation packages

cd ~
git clone https://github.com/cemanst/etf_maira_conveyor.git
cd ~/etf_maira_conveyor/ros2_ws
source /opt/ros/humble/setup.bash
rosdep install --from-paths \
  src/neura_ros2/neura_robot_description \
  src/neura_ros2/moveit_maira7m --ignore-src -r -y
colcon build --base-paths \
  src/neura_ros2/neura_robot_description \
  src/neura_ros2/moveit_maira7m \
  --packages-up-to moveit_maira7m
source install/setup.bash

3. Launch RViz and run one pick

In the same terminal, start the simulation and wait for Conveyor collision geometry installed.

ros2 launch moveit_maira7m conveyor_world.launch.py

In a second Ubuntu terminal, set the belt to 0.05 m/s and trigger a pick. Start recording before calling the service.

source /opt/ros/humble/setup.bash
source ~/etf_maira_conveyor/ros2_ws/install/setup.bash
ros2 param set /conveyor_world speed 0.05
ros2 service call /conveyor_world/run std_srvs/srv/Trigger '{}'

4. Show the hand trajectory

  1. Download the optional flange trail script and save it to your Ubuntu home directory. On Windows, you can copy the download from /mnt/c/Users/<Windows user>/Downloads/.
  2. Run the commands below in a third Ubuntu terminal before triggering the pick.
  3. In RViz, set Fixed Frame to maira7M_root_link. In Displays, choose Add → By display type → Marker and set its topic to /maira/flange_trail.
  4. Frame the whole belt and arm, then record one run from the approach through the lift. Restart the trail script for a clean take.
source /opt/ros/humble/setup.bash
source ~/etf_maira_conveyor/ros2_ws/install/setup.bash
python3 ~/maira_flange_trail.py
